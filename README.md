# Solar System & Milky Way Explorer

An interactive, browser-based educational visualization of the solar system traveling around the Milky Way.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies required.

## Publish with GitHub Pages

1. Push this folder to a public GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
4. Your site will be published at `https://YOUR_USERNAME.github.io/solar-system-galaxy/`.

## Notes

Planet distances, sizes, orbital speed, rotation speed, and galactic movement are illustrative, not to scale. Planet surfaces are procedurally drawn rather than photographic imagery.
